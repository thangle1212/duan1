Cheat Sheet
Tạo env Python 3.12 mới
conda create -n myenv python=3.12 anaconda -y
Kích hoạt môi trường
conda activate py312_datascience
Cài đặt gói qua conda-forge
conda install -c conda-forge pyspark -y
Xuất file cấu hình YAML
conda env export > environment.yml
Tạo lại Env từ file environment.yml
conda env create -f environment.yml
Điểm Nổi Bật Python 3.12
  • Tối ưu hiệu năng: CPython 3.12 nhanh hơn trung bình 5-10% so với 3.11.
  • Cú pháp Type Parameter (PEP 695): Khai báo generic gọn gàng hơn với từ khóa type.
  • F-string nâng cấp: Hỗ trợ lồng biểu thức và xuống dòng tự do hơn.
  • Cảnh báo lỗi thông minh: Gợi ý sửa lỗi ImportError và NameError chính xác hơn.
